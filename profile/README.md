## Who we are

We are a group of students at **Universitatea Politehnica Timișoara** building software for students and community. We aim to create a network of passionate members who want to contribute to the digital era through their ideas and expertise. 
We welcome both new commers, starting their project, or long time veterans of building ideas. The rule is simple: give back to the community.

## What we work on
 
At **Open Source Club UPT**, we believe any piece of code is worth writing if it solves a problem or does something in a new, interesting way. Here, you'll find:
- 🧩 a module someone needed for a bigger project
- 🌙 a script that fixed a very specific problem at 3AM
- 🛠️ a tool you'll use once a month and still feel proud to have built

We work across all kinds of areas, including but not limited to:
- 🌐 web & mobile development
- 🔌 embedded software & IoT
- 🤖 bash & automation scripts
- 🧠 AI tools & applications
- ⌨️ CLI tools & developer utilities
- 🎮 game development
- 🧭 browser extensions
- 📊 data pipelines & analysis
- 🌱 open-source contributions to existing projects
